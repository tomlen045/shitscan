# 💩 屎山代码鉴定所 SHITSCAN

## 新增：浏览器离线版

**下载一个 HTML 文件，双击打开就能用。无需 Python、账号或 API Key。**

1. 打开 [`offline.html`](offline.html)，使用 GitHub 文件页的 **Download raw file（下载原始文件）** 按钮保存。
2. 双击本地文件，在浏览器里打开；先点「试试祖传代码」。
3. 粘贴自己的代码，生成六项规则指标，并保存不含代码原文的 PNG 证书。

![浏览器离线版实际截图](docs/offline-desktop.png)

这是可下载的浏览器应用；本仓库目前未启用 GitHub Pages，仓库里的 HTML 文件页不是在线试玩页面。

### 两个版本怎么选

| | 浏览器离线版 `offline.html` | Python 版 `app.py` + `static/` |
|---|---|---|
| 启动 | 下载后双击 HTML | 运行 `python3 app.py` |
| 代码处理 | 当前浏览器内，无后台请求 | 发往你启动的本地 Python 服务处理 |
| 代码存储 | 不写浏览器持久存储，刷新清空 | 既有服务的隐私与保存行为见下文 |
| 结果 | 六项文本规则、证书 PNG、摘要 | 六维分析、排行榜及既有功能 |
| 评分 | 独立的离线规则 v1.0 | 原 Python 规则；与离线版不可直接比较 |

**两个版本都只适合娱乐与阅读线索提示。分数不代表真实代码质量、作者水平或维护成本。** 离线版不执行输入代码，不使用语法解析器，字符串、注释和语言风格会影响结果。

浏览器离线版已在 Chromium 下检查：断网使用、空输入与长度边界、中文及 emoji 计数、输入安全呈现、PNG 导出、390px 手机布局、清空和无网络请求。复现方式见 [`docs/offline-guide.md`](docs/offline-guide.md)。

## 原 Python 版

> 粘贴代码 → 3 秒出「屎山等级证书」→ 甩到群里让作者社死

![screenshot](docs/screenshot.png)

**SHITSCAN** 是一个零依赖的单文件代码娱乐鉴定工具：把那段你不敢动的祖传代码贴进来，3 秒生成屎山指数、六维分析、罪证现场和重构报价单，一键导出 750×1334 战报海报——每一次转发都是产品的广告位。

## ✨ 特性

- **六维鉴定**：复杂度 / 嵌套 / 命名 / 注释 / 重复 / 长度，加权算出屎山指数（0-100）
- **六级称号**：D 崭新出厂 → C 微瑕之作 → B 初具山形 → A 重度灾区 → S 镇店屎山 → SS 万年圣山 → SSS 代码成精
- **罪证现场**：定位最深嵌套、超长行、TODO 铁证、被静默吞掉的异常，逐条毒舌点评
- **重构报价**：按人日 × 时薪折算「老板欠你多少钱」，数字越离谱转发越起劲
- **战报海报**：Canvas 生成 750×1334 分享图，带唯一证书编号
- **屎山榜**：全站 TOP10 仅记录等级指标，供后来者瞻仰
- **隐私即卖点**：代码只在服务器内存鉴定，即用即焚，落盘的只有分数指标
- **零依赖**：纯 Python 标准库，`python3 app.py` 一条命令跑起来

## 🚀 快速开始

```bash
git clone https://github.com/tomlen045/shitscan.git
cd shitscan
python3 app.py
# 打开 http://127.0.0.1:8670
```

支持 Python / JavaScript / Java / Go / C 五种语言的自动识别（也可手动指定）。

## 🔒 隐私说明

- 粘贴的代码**只存在于鉴定请求的内存中**，用完即焚，不写磁盘、不打日志
- 服务端只持久化：等级、分数、语言、行数、报价等**指标字段**，用于总数统计与排行榜
- 仍然建议：别贴含密钥/密码的代码（虽然贴了也没存）
