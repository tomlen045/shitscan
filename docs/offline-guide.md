# 浏览器离线版：使用与验证

新增日期：2026-10-22。版本：offline-1.0。

## 快速使用

在 GitHub 打开根目录的 `offline.html`，点击 Download raw file 下载，然后双击本地文件。先试内置的「祖传代码」与「整理之后」两个示例，再放入自己的片段。

一份文件包含全部页面、规则和图片导出逻辑，没有字体或脚本 CDN。PNG 证书包含分数、行数、字符数和六个规则维度，不包含输入代码原文。保存文件和打开源码链接均需要用户主动点击。

## 规则边界

六项指标：分支关键字密度、括号/缩进深度、指定临时名称、待办标记、规范化重复行、超长行。每项归一到 0–100，权重分别为 20%、25%、10%、10%、20%、15%。分数越高，规则信号越多。

这是文本启发式，没有完整语法解析，注释、字符串、缩进、不同语言会带来误报。分数不是质量评审，不证明安全性，不用于绩效或人员评价。浏览器版和 Python 版规则不同，不能跨版本直接比较。

## 隐私

离线页面不发起网络请求，不使用 localStorage、cookie、遥测或第三方模型，不执行输入代码；关闭、刷新、清空页面后不保留输入。页面提供 `connect-src 'none'` 内容安全策略。浏览器插件、剪贴板、设备本身的安全仍取决于使用者的环境。

原 Python 版会把输入提交给本机服务。它与这个浏览器离线版是两种独立运行方式，请在宣传中明确区别。

## 检查结果

2026-10-22 在 Chromium（Playwright，文件协议，网络设为离线）检查：

- 空输入被提示；超过 100,000 字符被拒绝；中文与 emoji 按字符计数。
- 两个内置样例得分为 49 与 16，均在合法范围。它们是示例，不是对真实项目的质量测量。
- 输入中的 HTML 标签以文本处理，不进入结果 HTML。
- PNG 导出成功，尺寸 1080×1440。
- 390px 手机视口没有横向溢出。
- 清空后输入和结果均复位；浏览器持久存储为空。
- 本次操作记录到的 HTTP(S) 请求为 0，JavaScript 页面错误为 0。

测试程序：`scripts/offline-smoke.cjs`。需要自行安装 Node.js、Playwright 和 Chromium 后运行 `node scripts/offline-smoke.cjs`。已有 Chromium 时可用 `SHITSCAN_BROWSER` 指定可执行文件路径。脚本会把实际截图及证书写入 `docs/`。尚未逐一验证 Safari、Firefox 及手机原生浏览器的下载行为。
